TCP/IP Protocol: final revision notes

TCP/IP is a set of rules (protocols) that lets computers send data to each other across networks, including the internet. It is organised into 4 layers, and each layer does one job.

1. The 4 layers

Sending data: it moves down the layers (top to bottom). Receiving: it moves up.

4

4. TCP vs UDP

TCP

Connection-oriented, reliable, ordered. Resends lost data. Slower.

Used for: web, email, file download

UDP

Connectionless, no guarantee, no ordering. Very fast.

Used for: video calls, gaming, streaming

5. TCP 3-way handshake

"Can we talk?" → "Yes, can you hear me?" → "Yes. Let's start." After this, data transfer begins.

6. Example: opening a website

  1. DNS (application) converts google.com to an IP address.
  2. TCP (transport) opens a connection with the 3-way handshake.
  3. The browser sends an HTTP request, split into segments.
  4. IP (internet) routes the packets through routers to the server.
  5. Ethernet / Wi-Fi (network access) carries the frames over each link.
  6. The server replies the same way, and TCP rebuilds the page in order.

7. Viva questions

What is TCP/IP?A 4-layer protocol suite that defines how data is sent across networks and the internet.
TCP vs UDP?TCP is reliable, connection-oriented and slower. UDP is unreliable, connectionless and faster.
What is the 3-way handshake?TCP connection setup using SYN, SYN-ACK and ACK.
What is encapsulation?Each layer adds a header as data moves down. The receiver removes the headers (decapsulation) as data moves up.
IP address vs MAC address?IP is a logical address used for routing between networks and can change. MAC is a physical hardware address used inside a local network.
What is a port number?A 16-bit number that identifies an application or process (HTTP = 80, HTTPS = 443).
TCP/IP vs OSI?TCP/IP has 4 layers and is the model actually used. OSI has 7 layers and is a theoretical reference model. OSI Application, Presentation and Session map to TCP/IP Application. OSI Data Link and Physical map to Network Access.
Memory trick (top to bottom): All TCP Is Needed = Application, Transport, Internet, Network access.
